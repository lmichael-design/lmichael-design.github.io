What does CSS stand for?
Cascading Style Sheets.
What does background-image do?
It adds an image to an element's background.
What does grayscale(100%) do?
It makes an image completely black and white.
What does scaleX(2) do?
It makes an element twice as wide.
What does rotate(45deg) do?
It rotates an element 45 degrees clockwise.
What is a CSS transition?
It creates a smooth change between property values.
What does opacity control?
It controls how transparent an element is.
What does perspective do?
It creates a 3D viewing effect.
